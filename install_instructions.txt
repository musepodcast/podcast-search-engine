Muse Podcast Search Engine - Windows 11 Install Notes (NO CONDA)
Python 3.12.7 + (Optional) CUDA 12.4
---------------------------------------------------------------

Goal:
- Clone repo
- Create required data folders under %USERPROFILE%\podcast_data
- Setup Python venv
- Install requirements.txt (clean)
- Configure .env + HuggingFace token for pyannote
- Copy RSS config sample
- Run main.py

Notes:
- Use a short path like C:\repos\podcast-search-engine to avoid Windows long-path issues.
- After using setx or winget installs, close/reopen PowerShell so PATH updates apply.


1) Install Git + Python 3.12.7
PowerShell:

  winget install --id Git.Git
  winget install --id Python.Python.3.12 --version 3.12.7

Close and reopen PowerShell, then verify:
  git --version
  python --version


2) Install FFmpeg (required)
- Download FFmpeg and unzip so ffmpeg.exe is at:
  C:\ffmpeg\bin\ffmpeg.exe

Add to PATH:
  setx PATH "$env:PATH;C:\ffmpeg\bin"

Verify:
  ffmpeg -version


3) (Optional) Install CUDA Toolkit 12.4 + nvcc check
- CUDA 12.4 download archive:
  https://developer.nvidia.com/cuda-12-4-0-download-archive

(Optional) Add nvcc to PATH:
  setx PATH "$env:PATH;C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.4\bin"

Verify:
  nvcc --version

Note:
- Torch GPU support does NOT come from nvcc alone.
- You must install the correct PyTorch CUDA wheels (Step 7) for torch.cuda.is_available() to be True.


4) Clone the repo
  mkdir C:\repos -ea 0
  cd C:\repos
  git clone https://github.com/musepodcast/podcast-search-engine.git
  cd .\podcast-search-engine\


5) Create required data folders
These live under your user profile (C:\Users\<you>\podcast_data\...)

  mkdir $HOME\podcast_data\log -ea 0
  mkdir $HOME\podcast_data\podcasts -ea 0
  mkdir $HOME\podcast_data\podcasts_wav -ea 0
  mkdir $HOME\podcast_data\support_attachments -ea 0
  mkdir $HOME\podcast_data\transcripts -ea 0
  mkdir $HOME\podcast_data\watcher_json -ea 0


6) Create & activate virtual environment
Allow scripts for this session:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Create venv:
  python -m venv .venv312

Activate:
  .\.venv312\Scripts\Activate.ps1

Upgrade pip tools:
  python -m pip install --upgrade pip setuptools wheel


7) Install PyTorch (CPU OR CUDA)  <<< pick ONE option

7A) CPU-only (simplest)
  pip install torch torchvision torchaudio

Verify:
  python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
Expected: False


7B) NVIDIA GPU (CUDA 12.4) - recommended if you have an NVIDIA GPU
Install CUDA-enabled PyTorch wheels (uses PyTorch's CUDA runtime wheels):

  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

Verify:
  python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
Expected: True


8) Install project requirements
From repo root (venv activated):

  pip install -r requirements.txt

Notes:
- Do NOT use --no-deps.
- requirements.txt is clean now and should install normally.


9) Configure .env (required for pyannote diarization)
Create from sample:
  Copy-Item .env.sample .env
  notepad .env

HuggingFace token steps:
- Create account on HuggingFace
- Accept model terms:
  https://huggingface.co/pyannote/segmentation-3.0
  https://huggingface.co/pyannote/speaker-diarization-3.1
- Create token:
  hf.co/settings/tokens

Add to .env:
  PYANNOTE_AUTH_TOKEN=hf_...


10) RSS config file
Copy sample RSS config into watcher folder:

  Copy-Item .\master_rss.json.sample $HOME\podcast_data\watcher_json\master_rss.json


11) Run
From repo root (venv activated):

  python main.py


Whisper model VRAM reference (FYI)
- tiny / base: ~1 GB
- small: ~2 GB
- medium: ~5 GB
- large: ~10 GB
- turbo: ~6 GB (fast)

    Size	Parameters	English-only model	Multilingual model	Required VRAM	Relative speed

    base	74 M	    base.en	            base	            ~1 GB	        ~7x
    small	244 M	    small.en	        small	            ~2 GB	        ~4x
    medium	769 M	    medium.en	        medium	            ~5 GB	        ~2x
    large	1550 M	    N/A	                large	            ~10 GB	        1x
    turbo	809 M	    N/A	                turbo	            ~6 GB	        ~8x


Troubleshooting quick hits
- PATH not updated after setx -> close/reopen PowerShell
- Long path errors -> keep repo under C:\repos\...
- PowerShell activation blocked -> run ExecutionPolicy command in step 6
- torch.cuda False even after cu124 install -> update NVIDIA driver + re-run step 7B
- pip conflicts -> run: pip check

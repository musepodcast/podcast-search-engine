# Muse Podcast Search Engine – Code of Conduct

We keep this simple.

## 1. Our Mission
Build great projects.  
Write good code.  
Have fun doing it.
And break some things along the way.  

We’re here to create useful, open-source tools — not to police speech or dictate how people express themselves.

## 2. Free Speech & Open Discussion
- Say what you want, how you want.  
- Disagreements are fine, even encouraged.  
- Trolls, jokes, strong opinions — all welcome.  
- We do **not** moderate speech. If it’s legal, it stays.

## 3. What We Actually Care About
- Contributions that improve the project.
- Collaboration to make the codebase better.
- Sharing ideas openly and respectfully (respect is a choice, not a rule).

## 4. What We Don’t Do
- We don’t remove comments just because someone is offended.
- We don’t gatekeep participation based on beliefs, tone, or personality.
- We don’t waste time on drama — the focus is **code and creation**.

## 5. The Golden Rule
Don’t break the law, don’t spam the repo, and don’t mess with the infrastructure.  
Everything else is fair game.

---

**In short:** We’re here to build things together. The rest is noise — and we like to make noise.

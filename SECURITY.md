# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability, please email **musepodcast@protonomail.com**.

- We will acknowledge receipt within **48 hours**.
- We aim to provide a fix within **7 days** for critical issues.

## Supported Versions
We only patch the **main** branch for security issues.

| Version | Supported          |
| ------- | ------------------ |
| main    | ✅                  |
| older   | ❌                  |

---

**Do not** publicly disclose the vulnerability until we’ve had a chance to patch it.
